**Quiz Application**

About the Project
Quiz Application is an Android application developed using Java and XML. It allows users to test their general knowledge through a multiple-choice quiz.

 **Features**
- Welcome screen with Start Quiz button
- 10 general knowledge questions
- Four options for each question
- Randomized question order
- Instant feedback for correct and incorrect answers
- Green highlighting for correct answers
- Red highlighting for incorrect answers
- Final score and correct/incorrect answer summary
- Play Again option

 **Technologies Used**
- Java
- XML
- Android Studio
- Android SDK

 **How to Run**
1. Clone or download this repository.
2. Open the QuizApplication project in Android Studio.
3. Allow Gradle synchronization to finish.
4. Run the application on an Android emulator or compatible device.
