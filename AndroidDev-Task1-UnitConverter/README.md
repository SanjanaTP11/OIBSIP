Unit Converter Application



**Project Overview**



The Unit Converter is an Android application developed using Java and XML in Android Studio. It converts numerical values between different units of measurement.



**Technologies Used**



\- Android Studio

\- Java

\- XML

\- Android SDK



&#x20;**Features**



\- Convert length, weight, and temperature.

\- Select the measurement category using a dropdown.

\- Select source and target units using dropdowns.

\- Enter a numeric value and calculate the converted result.

\- Display the result with unit labels.

\- Validate empty and non-numeric input using Toast messages.

\- Update the available units when the category changes.



**Supported Units**

1. Length

\- Centimetres

\- Metres

\- Kilometres

\- Inches

\- Feet



2\. Weight



\- Grams

\- Kilograms

\- Pounds

\- Ounces



3\. Temperature



\- Celsius

\- Fahrenheit

\- Kelvin



&#x20;**How to Use**



1\. Open the application.

2\. Select a measurement category.

3\. Enter the value to convert.

4\. Select the source unit.

5\. Select the target unit.

6\. Press the Convert button.

7\. View the converted result.



&#x20;**Input Validation**



The application displays a Toast message if the input field is empty or the value cannot be parsed as a number.
