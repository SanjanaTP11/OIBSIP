**Android Calculator App**



**Oasis Infobyte Internship – Android Development**

Task 2: Calculator



**Description**

This project is a simple Android calculator application developed using Java and XML in Android Studio.



**Features**

\- Addition, subtraction, multiplication, and division

\- Decimal number calculations

\- Clear (C) functionality

\- Backspace functionality

\- Division-by-zero error handling

\- Simple and user-friendly interface



**Technologies Used**

\- Java

\- XML

\- Android Studio



**How to Run**

1\. Open the project in Android Studio.

2\. Allow Gradle synchronization to complete.

3\. Run the application on an Android emulator or compatible device.
